# 产品目标

## Goal

在 Linux 服务器上提供可长期稳定运行的 Go 服务：用户在任意普通 B站视频评论区 `@赛博琥珀自助机` 并给出时间范围后，服务识别视频与分P、生成经过体积优化且可选烧录弹幕的 GIF，再在同一视频评论区发布真正 `@` 发起者的一级带图评论。公开网页提供 BV/链接/分享文本解析、参数选择、持久任务、实时进度、预览与下载。

## 非目标

- 不绕过付费、地区、会员、登录、DRM 或内容权限。
- 不支持直播切片、互动视频分支、付费课程、番剧批量、完整视频下载、GIF 音频。
- 不允许匿名网页用户控制机器人账号发布评论。
- 不以 yt-dlp、BBDown、DownKyi/.NET、Python、Node.js 或浏览器自动化作为生产解析路径。

## MVP 范围

- 普通公开 UGC，BV/AV/完整链接/b23/分享文本，多P与 `p=N`。
- `MM:SS`/`HH:MM:SS` 和中英文命令参数。
- DASH 视频轨道、区间弹幕 Protobuf、ASS、FFmpeg GIF、自适应体积限制。
- SQLite 队列、崩溃恢复、通知游标与去重、一级带图评论、真正 `@`、提示回复、dry-run。
- Go embed Web、SSE、管理认证、扫码/Cookie 账号、指标、Docker/systemd/nginx、amd64/arm64。

## 后续扩展

- 在专用测试视频上建立显式开关保护的真实写入 E2E。
- 根据更多脱敏真实通知响应扩展兼容层与结构漂移告警。
- 将当前“保存后安全重启生效”的带审计运行设置扩展为不破坏队列语义的热重载。
- 分布式对象存储和多实例租约协调；更细致的弹幕权重策略。
- 经确认许可与风控后增加其他公开资源类型，但不增加绕过能力。
